# ADR-0017: CI/CD

- **Status:** Stub
- **Date:** 2026-05-04
- **Slice:** 1

## Context

Every PR must be checked before merge. Every merge must deploy. Rollback must be one click.

## Decision

To be drafted in Slice 1 (the CI workflow ships in the same commit as the Next.js scaffold).

### CI (GitHub Actions, `.github/workflows/ci.yml`)

Runs on every PR and every push to `main`:

1. `pnpm install --frozen-lockfile`
2. `pnpm typecheck` (`tsc --noEmit`)
3. `pnpm lint` (ESLint + Prettier check)
4. `pnpm test` (Vitest unit + integration)
5. `pnpm test:e2e` (Playwright against Vercel preview URL — requires preview deploy)
6. Lighthouse CI (perf, a11y, SEO budgets)
7. Block merge if any step fails

### CD (Vercel)

- Every push to a branch → preview deploy
- Every push to `main` → staging deploy (auto)
- Manual promote from staging → production

### Migration policy

- Database migrations live in `supabase/migrations/NNNN_description.sql`
- Migrations are forward-only (no down). Rollback = forward fix.
- Every migration is reviewed for: zero-downtime safety, RLS, index coverage.
- Production migrations gated on staging migration success.

### Rollback

- Vercel: instant rollback via dashboard ("redeploy previous").
- Database: forward-fix migration. PITR restore as last resort (ADR-019).

### Branch protection

- `main` requires: 1 PR review, all CI checks passing, up-to-date with main, signed commits.
- Direct push to `main` allowed only by owner for emergency hotfix.

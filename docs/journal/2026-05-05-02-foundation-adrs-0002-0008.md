## Decisions

- **One combined entry for 0002–0008.** Per-ADR entries would have been six near-empty files. The audit table per ADR captures per-ADR detail without entry sprawl.
- **CI guardrails added now, not later.** The ADR-0004 and ADR-0007 grep checks are project-wide policy enforcement, not feature-specific. They no-op against empty surfaces today and start enforcing the moment those surfaces get populated. That makes them foundation, not slice-feature.
- **No `lib/supabase/admin.ts` stub.** An empty stub invites the first developer to fill it without re-reading ADR-0007. Better to leave the file absent and force a deliberate creation when the first webhook arrives.
- **ESLint custom rules deferred.** Both ADR-0004 (`\$\{.*_cents}` display rule) and ADR-0006 (audit-policy rule) call for ESLint rules. Custom-rule plugins are non-trivial and there is no UI/server-action code to enforce against yet. Will revisit in slice 2 when first money-rendering and first auditable action arrive.
